# **App Name**: TaskFlow

## Core Features:

- Task List: Display a list of tasks with options to view, edit, and delete each task.
- Add Task: Allow users to add new tasks with fields for title, description, and due date.
- Edit Task: Enable users to modify existing tasks and save the changes.

## Style Guidelines:

- Primary color: Teal (#008080) for a professional and calming feel.
- Secondary color: Light gray (#D3D3D3) for backgrounds and subtle accents.
- Accent color: Orange (#FFA500) for interactive elements like buttons and highlights.
- Use a clean and responsive grid layout to ensure the application looks good on all devices.
- Use a set of consistent and simple icons from a library like FontAwesome or Material Icons.
- Subtle animations for transitions and interactions to improve user experience. For example, a fade-in effect when tasks are added or removed.
